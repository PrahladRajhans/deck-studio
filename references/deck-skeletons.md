# Deck skeletons

Starting sequences, not straitjackets: rewrite every title as a claim (document) or a beat (talk),
cut any slide the storyline does not need, and add one slide per extra claim. Format:
`type: what it says`. Mode D = document, T = talk. Direction = first pick (decision-trees.md T8).

## A. Consulting and strategy

**A1. Case competition final (D, 10-14 + appendix) · consulting-navy / editorial-warm**
cover (answer + key figure) → exec_summary (3-5 rows, ref'd) → agenda (spine) → chart / big_number:
situation → issue_tree or data_contrast: complication & root cause → chart / matrix: where to play →
options: scorecard → framework: the recommendation thesis → table or chart waterfall: financials →
timeline: implementation with owners → risks: register with mitigations → ask: decision, cost, figure
→ closing → appendix (backup tables, method, sources).

**A2. Case competition round 1 / written submission (D, 5-8) ·** cover → exec_summary → 3 claim slides
(one per key line) → options → ask. Every judging criterion has a titled slide.

**A3. Client readout / steering committee (D, 12-20) · consulting-navy**
cover → exec_summary → agenda → [per chapter: divider or agenda(active) → 2-4 exhibit slides] →
options or framework → roadmap or timeline → risks → actions (decisions needed today) → closing →
appendix.

**A4. Board ask / investment committee (D, 8-12) · boardroom-oxblood / finance-emerald**
cover (the ask + amount) → exec_summary → big_number or chart: why now → chart range: valuation or
returns → table: P&L / cash with total row → options (alternatives considered) → risks → ask →
closing → appendix.

**A5. Market entry (D) ·** cover → exec_summary → chart mekko (image): market structure → matrix: segment
attractiveness vs ability to win → compare / options: entry modes → chart waterfall: business case →
timeline → risks → ask.

**A6. Profitability diagnosis (D) ·** cover → exec_summary → chart waterfall: profit walk → issue_tree:
drivers → data_contrast: the hidden tension → chart / table per driver → framework: fix → actions.

**A7. M&A rationale (D) ·** cover → exec_summary → hub: strategic fit → chart range: valuation football
field → table: synergies (computed) → timeline: integration → risks → ask.

**A8. Pricing proposal (D) ·** cover → chart scatter: price vs value by competitor → chart image dumbbell:
current vs proposed → pricing: new tiers → chart waterfall: revenue impact → risks → ask.

**A9. Operating model / org redesign (D) ·** cover → exec_summary → before_after: today vs target →
hub or pyramid: capabilities → roadmap → actions → risks.

**A10. Sustainability / ESG report (D) · forest-sage** cover → kpi with deltas → chart line vs target →
columns: pillars → milestones → references.

## B. Reviews and updates

**B1. QBR / monthly business review (D, 6-10) · modern-teal**
cover → kpi: scorecard vs plan with deltas (no charts here) → chart waterfall: what moved and why →
1-2 deep-dive charts (charts only here) → risks or data_contrast → actions: decisions needed → next period.

**B2. Project status / ELP check-in (D, 5-8) ·** cover → kpi or milestones: where we are (done / now /
next) → table: what changed since last time → risks: owner, mitigation → actions: decisions needed →
references.

**B3. Ops review (D) ·** cover → kpi → chart image heatmap: performance by site × month → funnel or
process: where it breaks → actions.

**B4. Investor update (D) ·** cover → big_number: the headline metric → kpi deltas → chart line →
milestones → asks (intros, hires).

## C. Pitches

**C1. Venture pitch, Sequoia order (D/T, 10-13) · electric-launch / bold-signal**
cover (company purpose in one sentence) → statement or data_contrast: problem → before_after or
process: solution → big_number or milestones: why now → chart image mekko / big_number: market size
(bottom-up) → matrix or compare: competition → image / gallery: product → pricing or columns: business
model → team → chart line: financials / use of funds → ask (amount, use, milestone it buys).
Sequoia's list: purpose, problem, solution, why now, market size, competition, product, business
model, team, financials.

**C2. YC-style seed deck (T, 8-12) ·** cover (name + one-line description) → problem (real people) →
solution (few words) → traction (big_number / chart; may be lumpy) → insight (what you know others
don't) → business model → market → team (founders, no advisors) → ask (amount, what it buys, where
you'll be in a year). Kevin Hale (YC): legible, simple, obvious.

**C3. Kawasaki 10/20/30 (T) ·** 10 slides, 20 minutes, ≥ 30pt: problem → solution → business model →
underlying magic → marketing and sales → competition → team → projections and milestones → status
and timeline → summary and call to action.

**C4. Demo day / 3-minute pitch (T, 6-8) ·** cover → big_number: the problem's size → image_full: the
product in use → big_number: traction → team → ask.

**C5. Sales pitch / proposal to a client (D/T) ·** cover (their outcome) → data_contrast: their
problem in their numbers → before_after → columns: how we do it → faq: objections → pricing →
milestones: first 90 days → ask.

**C6. Partnership pitch (D) ·** cover → venn: shared ground → hub: what each brings → roadmap → ask.

**C7. Incubator / grant application (D) ·** cover → problem → solution → evidence (pilot numbers) →
milestones → budget table (computed) → team → ask.

## D. People and careers

**D1. Interview story deck (T, 6-9) · editorial-warm**
cover (the value you create, one line) → quote or image_full: the human hook → [3 × (divider question
→ kpi or big_number: the number that moved)] → process: how I work → statement: my first 30/60/90
days in their context → closing. Personal voice, ≤ 40 words a slide.

**D2. "Tell me about yourself" / intro (T, 4-6) ·** cover → milestones: the journey (3-4 points) →
columns: what I bring → statement: what I'm looking for.

**D3. Portfolio / case study (T, 8-12) · gallery-white ·** cover (hero image) → quote: the brief →
kpi: constraints → before_after / gallery: process → big_number: outcome → columns: what I learned.

**D4. Internship final presentation (D/T) ·** cover → exec_summary → before_after: what I found → chart:
impact (numbers the manager will confirm) → actions: handover → columns: what I learned.

**D5. Award / farewell / tribute (T) · luxe-noir / nordic-calm ·** cover → image_full → milestones:
the years → quote(s) from colleagues (real) → gallery → closing.

## E. Teaching, research, academic

**E1. Lecture / peer teaching (T, 12-20) · forest-sage / pastel-friendly**
cover → columns: learning goals → question: the hook → [per concept: statement (what it is) →
before_after (what it changes) → image or process (worked example) → question (check)] → table:
chapter summary (topic | key idea) → actions or question: practice → references.

**E2. MBA class presentation / case analysis (D/T, 8-12) ·** cover → exec_summary (answer) →
issue_tree: the case question → 3 analysis slides (charts / matrix / options) → framework:
recommendation → risks → question: discussion prompt for the class → references.

**E3. Group project (course) (D, 8-10) ·** cover → team → statement: question → process: method →
findings (one per slide) → compare: implications → limits → references.

**E4. Research readout / thesis defence (D, 10-20) · mono-ink**
cover → statement: research question → process: method → findings (one claim per slide, figure-first)
→ table: robustness → risks or bullets: limitations → statement: contribution → references.

**E5. Paper / book summary (D) ·** cover (citation) → statement: thesis → columns: key points → chart(s)
from the source (cite page) → faq: critiques → references. Build from source → summary → slides.

**E6. Workshop / training (T, 8-15) ·** cover → columns: agenda / goals → [per module: process (steps) →
image (demo) → compare (do / don't) → question (scenario)] → actions: try this week → closing.

## F. Marketing, brand, product

**F1. Campaign plan (D/T) · coral-studio / terracotta-editorial**
cover → big_number or quote: the consumer insight → statement: the idea → gallery: creative → funnel:
how it converts → roadmap or timeline: flighting → kpi: targets (measurable) → risks → ask (budget).

**F2. Brand strategy (D) ·** cover → journey: today's experience → venn: positioning sweet spot → pyramid:
brand house → columns: pillars → gallery: expression → roadmap.

**F3. Product launch (T) · electric-launch / dark-stage ·** cover → question: the frustration → image_full:
the product → columns: three things it does → data_contrast: before vs after → pricing →
milestones: availability → closing (call to action).

**F4. Marketing results / post-mortem (D) ·** cover → kpi deltas vs target → funnel → chart image slope:
channel shifts → compare: what worked / didn't → actions.

**F5. Social / social-media plan (T) ·** cover → columns: audiences → gallery: content pillars →
roadmap: calendar → kpi.

## G. Organisation, change, events

**G1. Town hall / all-hands (T) ·** cover → big_number: the year in one number → milestones → gallery:
people → statement: what's next → question: Q&A.

**G2. Change announcement (D/T) ·** cover → statement: what changes → before_after → process: what
happens when → faq: concerns → actions: who to ask.

**G3. Club event / fest (T, 6-12) · campus-bright / poster-yellow**
cover → columns: agenda → team (organisers) → gallery: highlights → roadmap: schedule → closing
(sign-up call to action).

**G4. Recruitment drive (T) ·** cover → big_number → columns: why join → team → milestones → closing (how
to apply, deadline).

**G5. Nonprofit / grant / CSR proposal (D) · forest-sage / heritage-india**
cover → image_full: the person helped (with consent) → big_number: scale of need → process: programme
→ table: budget (computed) → kpi: outcomes (measurable) → ask.

**G6. Policy brief (D) · public-sector**
cover → exec_summary → chart: the problem in data → options: policy choices scored → risks →
actions: implementation → references.

**G7. Webinar / conference talk (T, 20-40) ·** cover → question: the audience's problem → (no agenda) →
chapters with question dividers every 3-6 slides → at least one honest limitation slide → closing:
call to action → references.

**G8. Lightning talk (T, 5 min, 8-10 slides) ·** cover → question → 6 single-idea slides (big_number,
image_full, statement, data_contrast) → closing (one action).

**G9. Pecha Kucha (T, 20 slides × 20 s) ·** image-led only: image_full, big_number, statement, quote.
No bullets, no tables.

## H. Single slides that stand alone

**H1. One-page summary / placemat (D) ·** framework or exec_summary with dense rows; ≥ 12pt.
**H2. Elevator slide ·** big_number + 3 points.
**H3. Decision slide ·** ask with figure.
